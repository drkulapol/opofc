ลูกหนี้ค่ารักษา สิทธิเบิกได้ (OFC / จ่ายตรง กรมบัญชีกลาง)

ชนลูกหนี้รายตัวกับ Statement OFC

อัปโหลดไฟล์ลูกหนี้จาก HOSxP และไฟล์ STM (พึงรับ) จาก สปสช. ระบบจะจับคู่รายตัวด้วย AN / VN = SEQ NO แล้วสำรองด้วย HN + วันที่รับบริการ แสดงส่วนต่างและรายที่ยังไม่มี STM ไฟล์ทั้งหมดประมวลผลในเบราว์เซอร์นี้เท่านั้น ไม่ถูกส่งออกไปที่ใด

ไฟล์ที่ 1

ลูกหนี้รายตัว (จาก HIS)

.xls / .xlsx / .csv ที่มีคอลัมน์เช่น visit_date, vn, an, hn, fullname, claim_amount (ระบบเดาคอลัมน์ให้ แก้ได้ด้านล่าง)

ไฟล์ที่ 2

Statement OFC (STM_xxxxx_OP / IP)

เลือกได้หลายไฟล์พร้อมกัน หรือเลือกไฟล์ .zip ที่รวม STM ไว้ ไฟล์ซ้ำ (เลขที่เอกสารเดียวกัน) จะถูกนับครั้งเดียว

ดึงไฟล์ลูกหนี้จาก HOSxP XE

ลูกหนี้ OPD สิทธิเบิกได้ (OFC / O1) ปีงบประมาณ 2569
ขั้นตอน
  1. เปิดเครื่องมือรัน SQL ที่ต่อฐานข้อมูล HOSxP XE (PostgreSQL) ได้ เช่น เมนู SQL Query ใน HOSxP, pgAdmin หรือ DBeaver
  2. กด คัดลอก SQL แล้ววางลงในหน้าต่าง Query
  3. แก้ช่วงวันที่ในบรรทัด o.vstdate BETWEEN ให้ตรงงวดที่ต้องการตรวจ (ค่าเดิมคือ 1 ต.ค. 2568 ถึง 30 ก.ย. 2569 ใช้ปี ค.ศ.)
  4. รัน Query ผลลัพธ์จะมี 7 คอลัมน์: visit_date, vn, hn, fullname, pttype, pttype_name, claim_amount
  5. ส่งออกผลเป็น Excel (.xls หรือ .xlsx) หรือ CSV โดยไม่ต้องแก้ชื่อคอลัมน์ ให้คอลัมน์ vn เป็นข้อความ เพื่อไม่ให้ Excel แปลงเลขเป็น 6.81E+11
  6. อัปโหลดไฟล์นั้นในช่อง ไฟล์ที่ 1 ด้านบน แล้วตรวจกล่อง “คอลัมน์ในไฟล์ลูกหนี้” ว่าเลือก vn, hn, visit_date และ claim_amount ถูกต้อง
  7. ดาวน์โหลด Statement OFC (ไฟล์ STM_รหัสรพ_OPปีเดือน_งวด.xls) ให้ครบทุกงวดที่ครอบคลุมช่วงวันที่ข้อ 3 แล้วอัปโหลดในช่อง ไฟล์ที่ 2 เลือกหลายไฟล์หรือเป็น .zip ก็ได้
  8. ดูผลในแท็บ ไม่พบ STM และ มีส่วนต่าง แล้วกด ส่งออก Excel เพื่อเก็บไว้ตามตัดลูกหนี้

claim_amount = ค่ารักษาทั้งหมด (vn_stat.income) หักเงินที่ผู้ป่วยชำระแล้ว (rcpt_money) เลือกเฉพาะ visit ที่ไม่ได้ admit และยอดค้างมากกว่า 0

SELECT
    o.vstdate AS visit_date,
    o.vn,
    o.hn,
    TRIM(COALESCE(p.pname,'') || p.fname || ' ' || p.lname) AS fullname,
    o.pttype,
    pt.name AS pttype_name,
    COALESCE(vs.income,0) - COALESCE(vs.rcpt_money,0) AS claim_amount
FROM ovst o
JOIN vn_stat vs ON vs.vn = o.vn
JOIN patient p ON p.hn = o.hn
JOIN pttype pt ON pt.pttype = o.pttype
WHERE o.vstdate BETWEEN '2025-10-01' AND '2026-09-30'
  AND pt.hipdata_code = 'OFC'
  AND pt.nhso_code = 'O1'
  AND (o.an IS NULL OR o.an = '')
  AND COALESCE(vs.income,0) - COALESCE(vs.rcpt_money,0) > 0
ORDER BY o.vstdate, o.hn

แต่ละ REP ในไฟล์ STM ที่อัปโหลด
วิธีจับคู่และความหมายของสถานะ
  1. ถ้าลูกหนี้มี AN และ STM มี AN ตรงกัน จับคู่ด้วย AN (ผู้ป่วยใน)
  2. ถ้าไม่มี AN ใช้ VN ของ HOSxP เทียบกับคอลัมน์ SEQ NO ใน STM (ผู้ป่วยนอก OFC ส่ง SEQ = VN)
  3. รายที่ยังไม่ได้คู่ ใช้ HN + วันที่รับบริการ (เทียบกับวันเข้ารักษาหรือวันจำหน่ายใน STM) จับคู่แบบหนึ่งต่อหนึ่ง
  4. ถ้า VN/AN เดียวกันอยู่หลาย REP (เช่น ส่งแก้ไข) ระบบรวมยอดพึงรับทุก REP ให้ลูกหนี้รายนั้น
  5. ได้รับครบ พึงรับเท่ากับลูกหนี้ · ได้รับต่ำกว่า ต้องปรับลดลูกหนี้ส่วนต่าง · ได้รับสูงกว่า ลูกหนี้บันทึกต่ำไป · ไม่พบ STM ยังค้างรับ ตรวจการส่งเบิก · STM ไม่มีลูกหนี้ มีเงินโอนแต่ไม่พบในไฟล์ลูกหนี้
ออกแบบและพัฒนาโดย นายแพทย์กุลพล ตั้งรัตนาพิบูล
